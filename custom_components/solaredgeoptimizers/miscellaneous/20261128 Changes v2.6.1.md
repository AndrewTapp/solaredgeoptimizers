# Changes — v2.6.1 (2026-11-28)

Fixes multi-SMI layouts where more than one **ACTIVE** parent reuses the same
`displayOrder` ([Issue #80](https://github.com/AndrewTapp/solaredgeoptimizers/issues/80)).

No new Python dependencies (`manifest.json` remains `requirements: []`).

## Collapse: keep live SMI / inverter peers (Issue #80)

- `collapse_duplicate_inverter_slots()` still drops true phantom/replaced rows
  for a shared display slot (Issue #66: e.g. one ACTIVE tree + one INACTIVE empty).
- When **two or more** peers in the same slot are ACTIVE (or blank) **and each
  already has optimizers**, all of those live peers are kept instead of collapsing
  to the richest tree alone.
- SMI parents use portal **`name`** for the slot / duplicate-suffix key
  (`inverter_position_key`) when present, so sites like `SMI 1.1` / `SMI 2.1`
  both with `displayOrder` `"1"` stay distinct devices (`SMI` `{site}.1` /
  `{site}.2`) rather than losing the second tree.
